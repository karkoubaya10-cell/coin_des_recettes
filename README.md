# 🍽️ Coin des Recettes

Application web de gestion et de partage de recettes de cuisine développée avec Laravel.  
Elle permet aux utilisateurs de créer, consulter, modifier et supprimer des recettes, ainsi que de les organiser par catégories.

## 🛠️ Technologies utilisées
- PHP 8 / Laravel
- MySQL
- HTML5, CSS3
- Bootstrap 5
- JavaScript

## ⚙️ Installation et lancement
```bash
git clone https://github.com/karkoubaya10-cell/coin_des_recettes.git
cd coin_des_recettes
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve

## ✨ Fonctionnalités principales
- Authentification et gestion des rôles
- CRUD complet sur les entités
- Interface responsive
