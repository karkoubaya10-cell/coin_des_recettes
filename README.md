# 🍽️ Coin des Recettes

## 📌 Présentation

**Coin des Recettes** est une plateforme web de partage de recettes de cuisine.

Le projet a pour objectif de permettre aux utilisateurs de découvrir, publier et gérer des recettes de cuisine dans une interface simple et intuitive.

## ✨ Fonctionnalités

- 👤 Authentification des utilisateurs
- 🔐 Gestion des rôles Utilisateur / Administrateur
- 🍴 Création, modification et suppression des recettes
- 📂 Organisation des recettes par catégories
- 💬 Commentaires
- ❤️ Ajout de recettes aux favoris
- 🌐 Interface disponible en français et en anglais
- 📄 Génération de documents PDF
- 📊 Gestion des données avec une base de données relationnelle
